# Dr. Shakila Faruque: personal website

Static site (HTML, CSS, JS). No build step.

- Director General (T.C.), Bangladesh Livestock Research Institute
- Research: conservation and improvement of indigenous chicken and quail

## Run locally

Serve the folder over localhost and open it in a browser.

## Structure

```
index.html
assets/css/style.css
assets/js/main.js
assets/img/portrait.jpg
assets/favicon.svg
```

Raise the `?v=` number on the CSS and JS links after each change.

Personal details such as phone number, date of birth, family details and personal email are intentionally not published.
