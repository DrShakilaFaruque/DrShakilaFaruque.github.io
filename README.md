# Dr. Shakila Faruque: academic website

Static multi-page site (HTML, CSS, JS). No build step; hosted with GitHub Pages from `main`.

Pages: `index.html` (home), `about.html`, `research.html`, `publications.html` (search and filters), `experience.html`, `contact.html`.

```
assets/css/style.css
assets/js/main.js
assets/img/        portrait, BLRI campus photo, stock photographs
```

## Notes

- Run locally by serving the folder over localhost.
- Raise the `?v=` number on the CSS and JS links after each change.
- To add the BLRI emblem, save it as `assets/img/blri-logo.png` and add an `<img>` in the header and footer brand blocks.
- Phone numbers, date of birth, family details and school-level results from the CV are intentionally not published.
- Photos: portrait and campus photo from the BLRI website; other photographs are free stock images from Pexels.
